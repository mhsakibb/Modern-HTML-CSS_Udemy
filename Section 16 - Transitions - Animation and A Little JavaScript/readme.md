## Overview

This section builds on core HTML and CSS skills by introducing motion and interaction. The lesson examples demonstrate how to make interface elements change smoothly, transform visually, and animate through defined stages. A small amount of JavaScript connects user actions with interface behavior.

## Topics Covered

- **CSS Transitions** — Create smooth changes when CSS properties change, using transition properties such as duration, delay, and timing functions.
- **CSS Transform** — Move, scale, rotate, or skew elements with the `transform` property.
- **CSS Animations** — Define multi-step effects with `@keyframes` and animation properties such as duration, delay, iteration count, and timing function.
- **Hover & Interaction Effects** — Use visual feedback to make buttons and other interface elements feel more responsive.
- **Introductory JavaScript** — Practice small interactive behaviors alongside CSS effects.

## What You’ll Learn

- Understand when to use a **transition**, **transform**, or **animation**.
- Apply **timing functions**, **durations**, and **delays** to control motion.
- Create reusable animation sequences with **`@keyframes`**.
- Combine CSS styling with simple **JavaScript interactions**.
- Add purposeful motion while keeping interfaces clear and usable.
