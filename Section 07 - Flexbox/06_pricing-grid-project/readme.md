## Project Overview

This mini-project builds a clean pricing grid that compares **Free**, **Pro**, and **Enterprise** plans. Each card presents a price, a short description, a call-to-action button, and a list of included features. The layout uses **CSS Flexbox** to arrange the cards, with distinct color treatments to help emphasize the plans.

## Key Features

- **Three pricing plans:** Compare Free, Pro, and Enterprise options in one view.
- **Plan details and pricing:** Each card displays a price, a short plan description, and a list of included benefits.
- **Visual plan hierarchy:** Gradient heading backgrounds distinguish the Pro and Enterprise cards, while the Pro call-to-action receives stronger visual emphasis.
- **Flexbox layout:** Uses `display: flex`, spacing, and `flex-wrap` to lay out the cards and allow them to wrap when space is limited.
- **Styled call-to-action buttons:** Includes hover states to provide visual feedback when users point to the buttons.
- **Icon-supported feature lists:** Uses Font Awesome check icons to make plan benefits easy to scan.
- **Consistent visual design:** Applies the Montserrat font, rounded corners, shadows, spacing, and a contrasting page background.

- Style interactive-looking buttons with **`:hover` states**.
- Use external resources such as **Google Fonts** and **Font Awesome**.
- Structure repeated content with semantic HTML elements such as headings, paragraphs, links, and lists.
